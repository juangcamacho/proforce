# PROFORCE Treinamentos — Site institucional

Site estático (HTML, CSS e JavaScript puros) pronto para GitHub Pages.

## Estrutura
- `index.html` — página única com todas as seções
- `css/style.css` — estilos
- `js/main.js` — menu, animações, galeria, modal de cursos e formulário
- `assets/img` — logo, favicon e fotos otimizadas
- `assets/video` — vídeos dos treinamentos

## Publicar no GitHub Pages
1. Crie um repositório e envie o conteúdo desta pasta para a branch `main`.
2. Em **Settings → Pages**, selecione *Deploy from a branch*, branch `main`, pasta `/ (root)`.
3. O site ficará disponível em `https://<usuario>.github.io/<repositorio>/`.

O formulário de contato não precisa de servidor: ele monta a mensagem e abre o WhatsApp
ou o cliente de e-mail do visitante.
